# PostgreSQL Data Analysis: Northwind DB Portfolio

This project demonstrates my proficiency in writing advanced PostgreSQL queries, optimizing database performance, and solving business and analytical problems using the classic Northwind dataset.

## About the Dataset
The Northwind database is a sample database that represents a fictional trading company. It contains data about sales, customers, employees, products, and suppliers.

## Key SQL Skills Demonstrated
* **Complex Joins:** Combining multiple tables (`Orders`, `Customers`, `Employees`, etc.) to extract meaningful insights.
* **Aggregations & Analytics:** Using `GROUP BY`, `HAVING`, and window functions (`RANK()`, `PARTITION BY`).
* **Subqueries & CTEs:** Designing readable and efficient queries with Common Table Expressions.
* **Database Optimization:** Indexing and query execution plan analysis (`EXPLAIN ANALYZE`).

## Repository Structure
* `/schema` - Northwind database schema and data initialization scripts.
* `/solutions` - SQL scripts categorized by complexity and topics.
